# Polenchek — сайт по Figma-макету

Next.js 16 (App Router, React 19.3) · Tailwind CSS 4 · Motion (бывший Framer Motion)

## Запуск

```powershell
npm install
npm run dev      # http://localhost:4000
npm run build    # продакшн-сборка, все страницы статические
npm start
```

## Где что менять

| Что | Где |
| --- | --- |
| Тексты, цены, ссылки на соцсети, список работ | `src/content/site.ts` |
| Текст на главной под подписью Polenchek | `site.intro` в `src/content/site.ts` (пусто = скрыт; длинный текст растягивает панель вниз) |
| Аватар вместо розового круга | положить картинку в `src/assets/`, импортировать и указать в `site.avatar` |
| Новые работы в галерее | положить `.webp/.png/.jpg` в `src/assets/art/` и добавить в `gallery` в `site.ts` |
| Цвета, стекло, анимации переходов | `src/app/globals.css` |

## Анимации и Liquid Glass

- **Liquid Glass кнопки и меню** (`src/components/liquid-glass.tsx`) — в Chrome/Edge на ПК фон за стеклом
  реально преломляется (SVG displacement map в `backdrop-filter`), в Safari/Firefox и на телефонах — матовое стекло
  с теми же бликами. Нажатие — «желейная» пружина, блик следует за курсором.
- **Переходы между страницами** — ссылки Next.js открывают раздел сразу. Элементы нового экрана появляются с CSS-анимацией, меню остаётся интерактивным.
- **Появление элементов** — чистый CSS: стартует с первого кадра, до загрузки JS. Подписи «пишутся» слева направо,
  по ним периодически пробегает блик.
- **Появление при скролле** — CSS scroll-driven animations (`animation-timeline: view()`), без JavaScript.
- **Прокрутка** — нативная. Кнопки разделов плавно прокручивают галерею, а переходы по ссылкам и кнопке «Назад» обрабатывает браузер вместе с Next.js.
- **Галерея** — 3D-наклон карточек за курсором, переключатель разделов, карточка «перетекает» в полноэкранный
  просмотр; листание стрелками / ← → / свайпом, соседние работы подгружаются заранее.
- **Price** — всегда помещается в один экран: на ПК всё масштабируется от высоты панели, на телефоне — вкладки со свайпом.
- **Фон** — дрейф неба, мерцающие и падающие звёзды, параллакс за курсором.
- Всё отключается при системной настройке «уменьшить движение».

## Адаптив

ПК-раскладка повторяет фреймы шириной 1920 px из макета и масштабируется через container query units (`cqw`).
На телефоне всё перестраивается в колонку, ряды галереи становятся свайп-каруселями.

## Картинки

Исходники из `.fig` (62 МБ) сконвертированы в WebP (~3 МБ) скриптом:

```powershell
node scripts/import-figma-images.mjs <папка images из распакованного .fig>
```

`next/image` дополнительно отдаёт AVIF/WebP под размер экрана и показывает размытое превью при загрузке.

## Тесты

Автотесты (Playwright) гоняют продакшн-сборку в 4 окружениях: Chrome на ПК, Chrome на Android (Pixel 7),
Safari на Mac и Safari на iPhone 14 (движок WebKit).

```powershell
npm run build
npm run test:e2e      # 132 проверки, ~3 минуты
npm run test:report   # HTML-отчёт с трассировками упавших тестов
```

Что проверяется: загрузка всех страниц и 404, ошибки в консоли, один `h1`, `alt` у картинок, подписи у кнопок,
отсутствие горизонтального скролла, навигация (в т.ч. очень быстрые переключения и «Назад» с восстановлением
прокрутки), раскладка главной на 10 разрешениях (подпись не залезает под меню и на кнопки), Price в один экран
на 6 разрешениях и на телефоне, вкладки и свайп, «Examples →», галерея (переключатель разделов, загрузка всех
работ, лайтбокс: клавиши, закрытие, фокус, разблокировка скролла, центрирование), TOS, Liquid Glass
(преломление в Chrome / матовое стекло в остальных), режим «уменьшить движение».
